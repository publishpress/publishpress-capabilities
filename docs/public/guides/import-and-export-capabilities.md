# Import and Export Capabilities

In [PublishPress Capabilities](https://publishpress.com/links/capabilities), you’ll find a “Export / Import” tab by going to the “Backup” link.

This feature allows you to download all the roles and capabilities from one site and import them into another site. This export will include not just the basic capabilities, but also extra features such as “Editor Features”, “Admin Features”, “Admin Menus”, and “Nav Menus”.

![Export / import capabilities](https://docs-media.publishpress.com/publishpress-capabilities/export-import-capabilities-tool-bf8d289d0a.webp)

Once you’ve exported the settings, you can now use the “Import Settings” tool to import the settings to a new site. You will need to also have the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin installed on that site.

![Import user roles and capabilities](https://docs-media.publishpress.com/publishpress-capabilities/import-capabilities-9413c2875a.webp)
