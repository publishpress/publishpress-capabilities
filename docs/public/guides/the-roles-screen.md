# The Roles Screen

Table of Contents

- [Add a New User Role](#h-add-a-new-user-role)
- [Delete User Roles](#h-delete-user-roles)

[PublishPress Capabilities](https://publishpress.com/links/capabilities) has a feature called “Roles”. This screen allows you to see all the user roles available on your site. You can also create new roles and delete some roles.

![Roles Screen in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-capabilities/roles-screen-7ca1e0856b.webp)

*Roles Screen*

## Add a New User Role [#](#h-add-a-new-user-role)

On the top of the screen, you can click “Add New” and create new user roles for your site.

![](https://docs-media.publishpress.com/publishpress-capabilities/create-new-role-dfbfc7a290.webp)

*Create New Role*

## Delete User Roles [#](#h-delete-user-roles)

You can use the Roles screen to delete any user role, except for the default roles: Administrator, Author, Contributor, Editor and Subscriber.

If you delete a user role, any users in the role will be automatically added to the default role which is normally Subscriber.

![Delete Role](https://docs-media.publishpress.com/publishpress-capabilities/delete-role-6cd60cb184.webp)

*Delete Role*
