## Extra User Roles in WordPress [#](#0-toc-title)

By default, WordPress arrives with five default user roles: [Contributor](https://publishpress.com/knowledge-base/contributor/), [Subscriber](https://publishpress.com/knowledge-base/subscriber), [Author](https://publishpress.com/knowledge-base/author), [Editor,](https://publishpress.com/knowledge-base/editor) and [Administrator](https://publishpress.com/knowledge-base/administrator). However, when you start installing plugins, you may see many extra roles. For example, if you install Yoast SEO, there will be two new roles: “SEO Editor” and “SEO Manager”. If you install WooCommerce, you’ll see two more roles: “[Shop manager](https://publishpress.com/links/shop-manager)” and “Customer”. In this screenshot below, you can see some of these extra roles:

![WordPress user roles from plugins](https://docs-media.publishpress.com/publishpress-capabilities/extra-user-roles-7bf99b6960.webp)

What happens if you do want all these extra roles? Is it possible to delete these extra roles? Yes, you can safely delete WordPress user roles with [the PublishPress Capabilities plugin](https://publishpress.com/capabilities/).

## How to delete a WordPress user role [#](#h-here-s-how-to-delete-a-wordpress-user-role)

- Install the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin to your site.
- Go to “Role” in the WordPress admin menu.
- Click the “Delete” link under any role that has that available. For safety reasons, some roles can not be deleted.
- You’ll see a pop-up box. Click “OK” to delete the role.
- Any users in this role will be moved to the “Susbcriber” role or whatever is set to the default role.
