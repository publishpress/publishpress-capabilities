# BuddyPress Permissions in PublishPress Capabilities

With [PublishPress Capabilities Pro](https://publishpress.com/capabilities/), you can control who is able to create groups with the BuddyPress plugin.

Go to “Capabilities” in your WordPress admin menu and you will see a “bp create groups” permission.

If you check this box, users in this role will be able to create groups.
