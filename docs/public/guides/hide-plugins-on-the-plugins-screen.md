# Hide Plugins on the Plugins Screen (Pro)

This feature requires the Pro version of the PublishPress Capabilities plugin.

There is a feature available in [PublishPress Capabilities Pro](https://publishpress.com/links/capabilities) that allows you to hide specific plugins from the “Plugins” screen. For example, you may not want user in some roles to see a plugin such as “Classic Editor” is installed. This is possible using the “[Admin Features](https://publishpress.com/knowledge-base/admin-features-screen/)” option in the plugin.

![Classic Editor Plugins](https://docs-media.publishpress.com/publishpress-capabilities/classic-editor-plugins-d8960772a5.webp)

*Classic Editor Plugins*

To hide plugins, follow these steps:

- Go to the “Admin Features” area of [PublishPress Capabilities](https://publishpress.com/links/capabilities).
- Click the “Hide CSS Element Form” tab.
- Enter a label for this setting.
- in the “Element IDs or Classes” box, enter the path to the plugins PHP file. In this example, it is `classic-editor/classic-editor.php`

![Hide Classic Editor](https://docs-media.publishpress.com/publishpress-capabilities/hide-classic-editor-1-b99c4886ec.webp)

*Hide Classic Editor*
