The Admin Styles feature is in the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. This allows you to customize the WordPress admin area with your own branding. You can change the color scheme and visual features for the admin screens. It’s also possible to have different settings for different user roles.

## Admin Color Scheme [#](#0-toc-title)

The Admin Color Scheme setting allows you to change the colors for your WordPress admin area. You can choose from several core WordPress options: Default, Light, Modern, Blue, Midnight, Sunrise, Ectoplasm, Ocean, Coffee. You can also click the “Add Custom Style” button which allow you to create your own color scheme.

![](https://docs-media.publishpress.com/publishpress-capabilities/admin-styles-40e2e5a88e.webp)

The Custom Style Editor enables you to choose many different colors for features in the WordPress admin area. This screenshot below shows the “Blank Template” option. To save your custom colors, make sure to enter a name into the “Custom Style Name” field.

![](https://docs-media.publishpress.com/publishpress-capabilities/custom-style-admin-06a7a30b68.webp)

Alternatively, you can choose one of the pre-built custom styles that are provided with [PublishPress Capabilities](https://publishpress.com/links/capabilities). This screenshot below shows the “Cherry” custom style.

![Cherry Custom Style](https://docs-media.publishpress.com/publishpress-capabilities/cherry-admin-f753b09c66.webp)

## Admin Font and Font Size [#](#2-toc-title)

These settings allow you to select a different font and font size for the WordPress admin area. You can choose to customize the fonts for these areas of your site:

- Base font
- Body text
- Links
- Headings
- Admin Menu
- Admin Bar
- Form Fields
- Buttons

![Admin font size](https://docs-media.publishpress.com/publishpress-capabilities/admin-font-size-ad9eee2b18.webp)

PublishPress Capabilities provides a range of fonts to choose from including Arial, Verdana, Tahoma, Trebuchet MS, Segoe UI, Helvetica Neue, Noto Sans, Georgia, Times New Roman, Courier New, Monaco, System UI. You can also use the “Custom Value” tab to enter your own choice of font.

![Preset fonts in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-capabilities/font-selection-d54bc8613d.webp)

## Admin Styles Settings for Users [#](#4-toc-title)

The final settings on the Admin Styles screen allow you to override any choices made by individual users. The first setting who remove the admin color options from user profiles. The second setting will allow those options to remain visible, but they will be overridden by any choices on the Admin Styles screen.

![Admin Styles settings](https://docs-media.publishpress.com/publishpress-capabilities/admin-styles-settings-1-f53df6118c.webp)
