# The Admin Notices Feature

The “Admin Notices” feature is available in the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. This feature helps organize messages and advertisements in your WordPress admin area.

This screenshot is an example of the notices that are organized by this feature.

![Wordpress dashboard with admin notices](https://docs-media.publishpress.com/publishpress-capabilities/admin-notices-20056a290f.webp)

The “Admin Notices” feature in the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin will organize all these admin notices into a new area in the top-right corner of your screen. This screenshot shows the location of the “Admin Notices” area.

![PublishPress Capabilities Admin NOtices](https://docs-media.publishpress.com/publishpress-capabilities/screenshot-2025-02-17-at-125246e280afpm-7878d8147b.webp)

This “Admin Notices” area will show all the notices in a clean, organized area. Nothing is changed about the notices so you can deal with them as normal. The only difference is that you won’t be pestered by these notices on your main admin dashboard.

![](https://docs-media.publishpress.com/publishpress-capabilities/messages-hidden-27ea9cee8f.webp)

Every time there’s a new notice, you’ll get a notification icon in the toolbar. This screenshot shows that you have 7 new notifications. WordPress provides [four different types of admin notice](https://publishpress.com/knowledge-base/admin-notice-types/):

- **Success** (green): This means the the user triggered an operation which was successful.
- **Error** (red): This means the the user triggered an operation which was unsuccessful.
- **Warning** (yellow): There may be some issues with the currently selected settings.
- **Info** (blue): The user needs to be aware of a special message.

![Different types of admin notice](https://docs-media.publishpress.com/publishpress-capabilities/notices-toolbar-07eab77ac6.webp)

If you see a notice that isn’t useful, you can hide it by clicking “Remove this notice”. This will move the notice to the “Removed Notices” tab. You won’t get any notifications if this message appears again, but you will be able to view them under “Removed Notices” if you want access to them.

![Remove admin notices](https://docs-media.publishpress.com/publishpress-capabilities/remove-notice-57c2b28668.webp)

It’s possible to customize this feature in multiple ways. In the “Admin Notices” area of the plugin’s settings, you can customize what each user role sees. For example, in the screenshot below, you can choose which notifications are visible to users in the Administrator role. You can decide which admin notices appear in the “Admin Notices” area, and which notifications appear on the main dashboard.

![User role Admin Notices](https://docs-media.publishpress.com/publishpress-capabilities/user-role-admin-notices-dd742915a5.webp)

Finally, if you do want to disable this feature, go to the “Dashboard” area of PublishPress Capabilities. You can quickly go back to the default displaying for admin notices.

![Disable Admin Notices](https://docs-media.publishpress.com/publishpress-capabilities/disable-admin-notices-5d4efb9e49.webp)
