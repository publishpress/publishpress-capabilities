# What are Unique Capabilities for Taxonomies?

This feature of the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin allows you to add extra permissions to the Taxonomies on your site.

- Go to the “Capabilities” link in your WordPress admin area.
- This screenshot shows the default WordPress permissions for Categories and Tags:

![](https://docs-media.publishpress.com/publishpress-capabilities/term-taxonomies-capabilities-142d571bb2.webp)

- If you decide you want more specific permissions, you can go to the “Capabilities” screen and check the boxes in the “Unique Capabilities for Taxonomies” area:

![](https://docs-media.publishpress.com/publishpress-capabilities/unique-capabilities-for-taxonomies-ee228d7d86.webp)

- Here’s what the permission options look like after you’ve checked all those boxes. You can now give the “Manage” permissions to all the taxonomies on your site:

![](https://docs-media.publishpress.com/publishpress-capabilities/term-taxonomies-capabilities-details-c19e81a3f2.webp)
