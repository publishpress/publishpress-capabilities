# How to Hide Dashboard Widgets

The [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin allows you to hide widgets on the WordPress admin dashboard. This is possible using the “[Admin Features](https://publishpress.com/knowledge-base/admin-features-screen/)” option in the plugin.

- Install the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin.
- Go to Capabilities > Admin Features in your WordPress menu.
- Choose a user role from the dropdown box in the top-left corner.
- Scroll down to the “Dashboard widgets” tab.
- You can now check the box for any widget you want to disable for this user role:

![Hide Widgets](https://docs-media.publishpress.com/publishpress-capabilities/hide-widgets-133f3060ae.webp)

*Hide Widgets*

The settings in the screenshot above will produce the view shown in the screenshot below. All your dashboard widgets are hidden.
