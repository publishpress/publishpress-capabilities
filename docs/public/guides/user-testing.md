# Getting Started With User Testing

Table of Contents

- [How to Use the User Testing Feature](#h-how-to-use-the-user-testing-feature)
- [Who Can Use the User Testing Feature?](#h-who-can-use-the-user-testing-feature)

If you run a WordPress website which allows users to log in, you probably spend a lot of time answer accounting questions or solving website bugs for your users.

The “User Testing” feature in the [PublishPress Capabilities](https://publishpress.com/capabilities/) plugin allows you to browse our site and see exactly what the user sees. You can test the user’s account without resetting their password.

## How to Use the User Testing Feature [#](#h-how-to-use-the-user-testing-feature)

To use this feature, you must be logged in as an Administrator.

One way to access this feature is via the “Users” screen. On this screen, you’ll see a “Test this user” link under each user. In the screenshot below, clicking the link will allow me to test the site as a user in the Author role.

![Test this user feature in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-capabilities/test-user-link-822b7f3412.webp)

It’s also possible to access this feature via the admin bar of your site. You can click the “User Testing” box and search for any user you want to test:

![User testing admin bar](https://docs-media.publishpress.com/publishpress-capabilities/user-testing-bar-0d33524665.webp)

After clicking to test a user, you will be able to browse the site as that user. In the admin area, there will be a User Testing reminder notice on the top of the site, showing you which user role you are testing. That notice has a “Return to Administrator view” link and so does the profile dropdown menu in the top-right corner.

![Admin area Return to Administrator view feature in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-capabilities/admin-user-testing-f34e49fb76.webp)

On the front of the site, you’ll also a similar notice in the footer area of your site content.

![User Testing toolbar link in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-capabilities/frontend-user-testing-f083266bb4.webp)

All of the User Testing features be enabled or disabled in the “Settings” area of [PublishPress Capabilities](https://publishpress.com/links/capabilities). You can also exclude roles from being available in the User Testing feature.

![user testing settings](https://docs-media.publishpress.com/publishpress-capabilities/user-testing-settings-134cd1443b.webp)

## Who Can Use the User Testing Feature? [#](#h-who-can-use-the-user-testing-feature)

By default, only users in the Administrator role can access the User Testing feature. If you want to grant access to other users, give them the “manage capabilities” capability.

This screenshot below shows the “Capabilities” screen in [PublishPress Capabilities](https://publishpress.com/links/capabilities). We are giving users in the “Editor” role access to the User Testing feature.

![User Testing Feature access](https://docs-media.publishpress.com/publishpress-capabilities/user-testing-603a35caba.webp)
