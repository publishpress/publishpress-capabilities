# Restore Permissions to the WordPress Defaults

If you really need to clean up and refresh your site, [PublishPress Capabilities](https://publishpress.com/links/capabilities) does allow you to restore the default WordPress permissions.

Click the “Reset Roles” tab. Before you take this step, make sure to read the warning:

> “WARNING: This will delete and/or modify stored role definitions. If you have installed any plugin that adds new roles or capabilities, these will be lost.It is recommended to use this only as a last resort!”

If you want to proceed, click the “Reset to WordPress defaults” button.

![Reset Roles](https://docs-media.publishpress.com/publishpress-capabilities/reset-roles-75bfb9d475.webp)

*Reset Roles*

[PublishPress Capabilities](https://publishpress.com/links/capabilities) will ask you if you’re really sure you want to do this. Click “OK” to continue. Once the process is complete, you’ll see the message, “Roles and Capabilities reset to WordPress defaults”.

![reset roles and capabilities](https://docs-media.publishpress.com/publishpress-capabilities/do-you-approve-a27479d873.webp)
