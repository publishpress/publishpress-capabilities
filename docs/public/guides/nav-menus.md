# The Navigation Menus Screen

Table of Contents

- [Getting Started With Navigation Menus](#0-toc-title)
- [The Navigation Menus Screen and Full-Site Editing](#1-toc-title)

This guide will show you how to use the “Navigation Menus” screen in the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. This screen allows you to block access to frontend menu links in WordPress. This is useful because a default WordPress site does not give you way to control the visibility of your links.

This feature allows you to remove access to menu links for a user role. It can not to give access to a menu link if a user role does not already have access.

This feature is available in both the Free and Pro version of [PublishPress Capabilities](https://publishpress.com/links/capabilities).

## Getting Started With Navigation Menus [#](#0-toc-title)

- To start changing access to menu links, go to “Capabilities”, then “Nav Menus” in your WordPress admin menu.
- Look in the top-left corner for the user role you want to edit:

![User dropdown for Nav Menus screen](https://docs-media.publishpress.com/publishpress-capabilities/nav-menus-dropdown-c4f5845804.webp)

- If your website has menu links, you will see them in the main area of this screen, as in this image below:

![](https://docs-media.publishpress.com/publishpress-capabilities/nav-menu-example-905e513ec1.webp)

In the image below, users in the “Author” role will not be able see or use any of the menu links marked in red.

![Menu Blocked](https://docs-media.publishpress.com/publishpress-capabilities/menu-blocked-d3440339cb.webp)

In addition to blocking access for user roles, you can also block access for all “Logged In User” and all “Logged Out Users”.

![Logged In Logged Out](https://docs-media.publishpress.com/publishpress-capabilities/logged-in-logged-out-c0f6ace8ef.webp)

## The Navigation Menus Screen and Full-Site Editing [#](#1-toc-title)

The Navigation Menus feature does have support for Full-Site Editing in WordPress. In addition to controlling access to menu links, [PublishPress Capabilities](https://publishpress.com/links/capabilities) can also control access to some blocks that are placed inside menu. These supported blocks include Site Logo, Social Icons, Search, and Page List.

![](https://docs-media.publishpress.com/publishpress-capabilities/other-blocks-menu-13237542ce.webp)

The Full-Site editing menus will appear as in this screenshot below. In this image, you can see a mix of page links and blocks. Access to all these can be blocked using the Nav Menus feature.

![](https://docs-media.publishpress.com/publishpress-capabilities/full-site-blocks-menu-31e25af187.webp)
