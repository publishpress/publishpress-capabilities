# Change the Name and Icon for Admin Menu Links

The [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin allows you to change the name and icon for each link in the WordPress admin menu. You can do this via the “[Admin Menus](https://publishpress.com/knowledge-base/admin-menus-screen/)” screen in [PublishPress Capabilities](https://publishpress.com/links/capabilities).

If you click on the pencil icon you will be able to change the name of the admin menu link. In the screenshot below, I’m changing “Dashboard” to “Your Dashboard”.

![Admin menu link](https://docs-media.publishpress.com/publishpress-capabilities/change-admin-menus-a6e73a604b.webp)

If you click on the “Change Icon” you can also change the icon for this menu link.

![Choose new admin menu icon](https://docs-media.publishpress.com/publishpress-capabilities/change-icon-1ad0fd62b8.webp)

Every time you make one of these changes, you can decide whether to do it for one user role, or all users on your site.

![Change admin menu for users](https://docs-media.publishpress.com/publishpress-capabilities/admin-menu-roles-a66b999b4a.webp)

In this next screenshot, you can see that “Dashboard” is now called “Your Dashboard” and has a new icon.

![New dashboard icon and name](https://docs-media.publishpress.com/publishpress-capabilities/new-admin-menu-link-2e2b3f8f6d.webp)
