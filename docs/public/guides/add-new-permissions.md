# How to Add New WordPress Capabilities

The [PublishPress Capabilities](https://publishpress.com/capabilities/) plugin allows you add permissions that might not be available on your site currently.

In this example, I’m adding the [erase_others_personal_data](https://publishpress.com/wordpress-permissions/erase-others-personal-data/) permission.

- After installing [PublishPress Capabilities](https://publishpress.com/links/capabilities), go to “Capabilities” in the WordPress admin menu.
- In the top-left corner, choose the role you want to edit.
- In the “Add a New Capability” box, enter `erase_others_personal_data`.
- Click “Add to role”.

![](https://docs-media.publishpress.com/publishpress-capabilities/add-new-capability-72e7d3337b.webp)

- Look in the “Additional Capabilities” area and you’ll see your new permission. In this case, the box says “erase others personal data”.

![](https://docs-media.publishpress.com/publishpress-capabilities/erase-other-personal-data-edited-794d6250b3.webp)
