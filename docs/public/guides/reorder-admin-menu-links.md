# Reorder Admin Menu Links

The [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin allows you to re-arrange the menu links in your WordPress admin menu. You can do this via the “[Admin Menus](https://publishpress.com/knowledge-base/admin-menus-screen/)” screen in [PublishPress Capabilities](https://publishpress.com/links/capabilities).

It’s possible to re-arrange the admin menu links. In this image below, I’m clicking on the “Move up” arrow next to the “Posts” link.

![Admin Menus](https://docs-media.publishpress.com/publishpress-capabilities/screenshot-2024-11-15-at-114708e280afam-8f4e18c64e.webp)

You can see the result in this next screenshot. The “Posts” link in the admin menu is now above the “Your Dashboard” link. These changes will impact all the user roles, so if you reorder the “Posts” link, this will be done for all the user roles.

![Admin Menu Restrictions](https://docs-media.publishpress.com/publishpress-capabilities/rearrange-admin-links-c9c0e9323c.webp)
