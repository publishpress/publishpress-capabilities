# Adding Multiple Roles to a User

By default, there are five users roles in WordPress. Everyone with an account on your site will be placed into one of these five roles: Subscriber, Contributor, Author, Editor, Administrator.

It is possible to place users into multiple roles thanks to the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin.

- Install the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin.
- Go to Setting > Roles and make sure you enabled both settings.

![Multiple Roles](https://docs-media.publishpress.com/publishpress-capabilities/multiple-role-setting-6fae67983a.webp)

- Go to the “Users” link in your WordPress admin menu.
- Either edit existing users or create new users.
- The “Role” field will now be able to accept more than one choice:

![Multiple Roles](https://docs-media.publishpress.com/publishpress-capabilities/multiple-roles-c7fded3fe4.webp)
