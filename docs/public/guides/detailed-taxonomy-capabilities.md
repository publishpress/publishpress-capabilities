# Detailed Capabilities for Taxonomies

The “Detailed Capabilities for Taxonomies” area in [PublishPress Capabilities](https://publishpress.com/links/capabilities) is related to[the Unique Capabilities for Taxonomies box](https://publishpress.com/docs/taxonomy-specific-capabilities/), but goes one step further.

If you check the boxes shown below, you will see extra permissions for all your taxonomies:

![](https://docs-media.publishpress.com/publishpress-capabilities/detailed-capabilities-for-taxonomies-e195af73cd.webp)

This screenshot shows the default WordPress permissions for Categories and Tags:

![](https://docs-media.publishpress.com/publishpress-capabilities/term-taxonomies-capabilities-142d571bb2.webp)

This screenshow below shows all the extra permissions you will see thanks to “Detailed Taxonomy Capabilities’. You will now see that you can give “Manage”, “Edit” and “Assign” permissions for all your taxonomies.

![](https://docs-media.publishpress.com/publishpress-capabilities/term-taxonomies-detailed-4f04c0ae90.webp)
