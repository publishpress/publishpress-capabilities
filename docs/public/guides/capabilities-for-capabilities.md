# Capabilities for PublishPress Capabilities

[PublishPress Capabilities](https://publishpress.com/links/capabilities) has individual capabilities to control access to all the main screens. These will be available immediately when you install the Capabilities plugin.

These capabilities control access to the following areas:

- manage_capabilities_dashboard: Controls access to the “Dashboard” screen.
- manage_capabilities_roles: Controls access to the “[Roles](https://publishpress.com/knowledge-base/the-roles-screen/)” screen.
- manage_capabilities: Controls access to the “[Capabilities](https://publishpress.com/knowledge-base/capabilities-screen/)” screen.
- manage_capabilities_editor_features: Controls access to the “[Editor Features](https://publishpress.com/knowledge-base/editor-features/)” screen.
- manage_capabilities_admin_features: Controls access to the “[Admin Features](https://publishpress.com/knowledge-base/admin-features-screen/)” screen.
- manage_capabilities_admin_menus: Controls access to the “[Admin Menus](https://publishpress.com/knowledge-base/admin-menus-screen/)” screen.
- manage_capabilities_profile_features: Controls access to the “[Profile Features](https://publishpress.com/knowledge-base/profile-features-screen/)” screen.
- manage_capabilities_nav_menus: Controls access to the “[Nav Menus](https://publishpress.com/knowledge-base/nav-menus/)” screen.
- manage_capabilities_user_testing: Controls access to the “[User Testing](https://publishpress.com/knowledge-base/user-testing/)” feature.
- manage_capabilities_backup: Controls access to the “[Backup](https://publishpress.com/knowledge-base/backup-restore-permissions/)” screen.
- manage_capabilities_settings: Controls access to the “Settings” screen.
