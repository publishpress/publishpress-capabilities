# The Admin Menus Screen

This guide will show you how to use the “Admin Menus” screen in the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. You can use this feature to edit, change, add or remove links from the WordPress admin menu.

With the “Admin Menus” feature you can customize the WordPress admin menu to meet the different needs of each user role. Here are some of the features on the Admin Menus Screen:

- [Control who can access each menu links](https://publishpress.com/knowledge-base/access-control-for-admin-menus/).
- [Re-arrange the menu links](https://publishpress.com/knowledge-base/reorder-admin-menu-links/).
- [Change the name and icon for links](https://publishpress.com/knowledge-base/change-name-icon-admin-menus/).
- [Add new menu links](https://publishpress.com/knowledge-base/add-new-admin-menu-links/) (Pro version)
